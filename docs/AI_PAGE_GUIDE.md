# AI 可引導的 App 頁面

AI 會收到 App 固定的頁面名稱及操作說明。回答可提出開啟按鈕；實際切換由使用者點擊，只支援下列已實作的固定頁面。不能由 AI 指定網址、代替操作或保證資料已更新。部分頁面可能需要登入、連線或受功能開關限制。

| 頁面 | 主要使用方式 |
| --- | --- |
| 首頁 | 公告、天氣、今日資訊與功能快捷入口 |
| 備忘錄 | 查看及新增待辦、設定期限與提醒、連結課程 |
| 課表 | 查看／編輯每週課程，點課程開啟詳情及可用 Moodle 內容 |
| 交流區、個人頁 | 查看公開討論；進入學校帳號、隱私與其他設定 |
| 學校帳號與同步 | 連結校務及 Moodle、更新本機保存的帳密 |
| 成績與排名、畢業門檻 | 選擇學期查看校方資料及門檻預覽 |
| 校方新聞、常用連結 | 閱讀學校新聞或開啟學校網站 |
| YouBike、校園地圖 | 查看站點可借還數量或校園設施 |
| 早餐、午餐、晚餐、宵夜 | 查看餐廳資料、評分與評論 |
| 新生清單 | 查看及勾選新生事項 |
| 課程查詢 | 按學年、學期或課名搜尋並加入課表 |
| 隱私設定、功能建議、回報問題 | 管理個人資料設定、提出建議或回報問題 |

聊天標題列選單可切換 App 資料／成績授權、執行校方登入診斷；鍵盤顯示時可按鍵盤圖示收合，也可向下捲動收合。AI 介面 Markdown 解析器沿用 ntpu-ai-vscode 的 markdown-it、KaTeX 與 highlight.js，離線呈現、禁用原始 HTML、圖片以文字參照呈現；各第三方授權隨 App 打包。原生頁面按鈕只識別程式內定義的代碼。

個別課程與單筆備忘錄沒有任意 ID 跳轉；應先前往課表或備忘錄，再由使用者選取。清單不代表已完成所有頁面的介面重設或真機驗收。
