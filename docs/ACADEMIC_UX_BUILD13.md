# 校務整合介面修正：build 13

日期：2026-11-02。延續 1.4.0（12）的實機回報，行銷版本保持 1.4.0。

## 使用體驗

- 學校帳號頁只保留登入、連線／隱私說明及同步狀態。登入按鈕立即顯示進度、禁止重複操作；失敗保留輸入，成功後清除密碼並收起輸入欄。已連結帳號可選重新登入；解除連結移至工具列。
- 課表預覽與確認匯入移至「課表 → 校務課表預覽與重新整理」。首頁快捷區只新增「成績與排名」「畢業門檻」兩個小入口，移除大面積校務清單與首頁的 Moodle 已繳交區。
- Moodle 已繳交建議移至備忘錄，仍須本人確認才標記完成。
- 新增 Moodle 類型與既有篩選列整合，舊匯入的預設作業類型會遷移，手動改成其他類型者保留。
- Moodle 說明初始化至備註。後續只有尚未手動修改的來源文字會更新；舊備註非空時保留並補上來源說明，不刪私人內容。
- 作業優先連結來源課程 UUID，沒有匯入紀錄時比對既有課表的名稱與教師；有歧義不亂配。備忘錄詳情可直接選擇或解除課程連結。課程選單保留原先選中的節次 UUID，避免同課多節去重後選中值消失。

## 原生資料與首次開啟

成績、排名、畢業門檻不再載入 WebView，也不執行校務頁面 JavaScript。SwiftSoup 僅解析資料；SwiftUI List／Section／LabeledContent／DisclosureGroup 顯示原生內容。

- 成績：`.card.my-4`、`.card-title`、`table.table-striped`、`sem1bg`／`sem2bg`，核對中文欄名後分開學期課程與統計。移除 `.lang-en-US`，避免雙語重複。
- 排名：`.container.my-2 > .card`、`.datasheets`、`ul.datarows`；另支援沒有學期 strong 的累計成績卡。
- 畢業：`tag_total`／`tag_chinese`／`tag_english`／`tag_pe`／`tag_general` 與 `required`／`option`／`common`／`other` 固定 ID，解析進度、門檻、課程與修習狀態，不自行判定畢業資格。
- build 12 舊 HTML 快取以背景工作轉成結構化資料。新回應只存結構化欄位。舊快取缺少必要 selector 時重新取資料，不嘗試用未知格式猜數值。
- 首次無資料、背景更新中、失敗保留舊資料與帳號切換均使用明確狀態；成績頁不在 body 中啟動 WebKit 或解析 HTML。

目前沒有取得該次 iPhone crash log，因此不能把 WebKit／快取列為已證實根因。已移除該呈現路徑並加上首次開啟與舊快取處理；是否完全排除原先閃退，仍需安裝 build 13 冷啟動確認。
