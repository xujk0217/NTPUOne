## 本機資料庫

- App 的課表與備忘錄統一由 `CoreDataManager` 擁有同一個 container／context，移除三套重複初始化。
- 載入失敗時顯示錯誤與重試入口；成功載入後才建立畫面資料模型，避免把載入失敗當作空資料。
- 儲存失敗顯示提示並保留待儲存變更，可重新嘗試。課程與備忘錄的主要儲存失敗會回報到共同提示。
- Widget 改為唯讀開啟既有 App Group 資料庫；不再強制解包路徑或 `fatalError`。資料庫暫時不可用時返回空內容，等下一次 timeline 更新再嘗試。
- 未刪除、重置或以另一個空資料庫取代原始資料。CloudKit schema 與 Firebase security rules 沒有變更。
