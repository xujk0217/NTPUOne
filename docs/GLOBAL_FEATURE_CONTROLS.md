# 管理員全體功能開關

管理後台提供「顯示廣告」及三個 AI 助理開關。App 監聽 Firestore `appSettings/features`。停用 AI 會收起入口並停止進行中的 App 回覆與提醒；停用廣告會套用至 App 的廣告呈現與獎勵廣告入口，不會修改用戶原有去廣告期限。

| AI 開關 | Firestore 欄位 | 套用條件 |
| --- | --- | --- |
| App Store 正式版 | `aiEnabled` | 正式發行、安裝來源辨識失敗，以及支援共用開關的舊版 |
| TestFlight | `aiEnabledTestFlight` | StoreKit 驗證的沙盒 App 安裝交易 |
| Xcode 本機測試版 | `aiEnabledDevelopment` | Debug、模擬器或 StoreKit 的 Xcode 環境 |

同一個 build 可以在 TestFlight 開啟 AI，並在 App Store 正式版關閉 AI。三個欄位缺少時各自預設開啟。新版本會等到取得設定及判斷安裝來源後才顯示 AI。

設定採 Firestore 安全規則，所有人可讀，且僅管理員與開發者能寫入支援的布林欄位。2026-11-25 已將三路開關的規則部署至 `ntpuone-d8fad`，並確認線上規則與本機一致。Firebase 規則測試 API 的九項模擬均通過，涵蓋匿名讀取、管理員與開發者寫入、舊版欄位更新，以及拒絕一般使用者寫入、錯誤型別、未知欄位與刪除。

分流適用於支援三路開關的新版本。離線裝置可能仍沿用快取設定，恢復連線後會收到更新。這些設定控制 App 內的入口及行為。

舊使用者已登入且尚未連結學校時，使用一次性的帳號提示版本重新顯示學校連結提示，已連結的帳號不強制重登；使用者可略過。App 資料儲存或授權尚未就緒時不顯示，稍後可重試。
