# 管理員全體功能開關

管理後台提供「顯示廣告」與「啟用 AI 助理」。App 監聽 Firestore `appSettings/features`，欄位缺少時預設開啟。停用 AI 會收起入口並停止進行中的 App 回覆與提醒；停用廣告會套用至 App 的廣告呈現與獎勵廣告入口，不會修改用戶原有去廣告期限。

設定採 Firestore 安全規則，所有人可讀，只有既有管理員或開發者權限可寫，且僅允許布林值。2026-11-03 已先核對線上舊規則與 Git 基準一致，再部署並核對結果。以 Firebase 規則測試 API 模擬匿名讀取、一般使用者寫入、管理員布林寫入及錯誤型別，四項符合預期；尚未以實際手機和管理員帳號驗收。只有安裝包含此功能的 App 才會遵守開關；離線設備及舊版本不能保證即時受控。這是客戶端功能控制，不是 NTPU AI 服務或廣告平台的伺服器端停用。

舊使用者已登入且尚未連結學校時，使用一次性的帳號提示版本重新顯示學校連結提示，已連結的帳號不強制重登；使用者可略過。App 資料儲存或授權尚未就緒時不顯示，稍後可重試。
