# 校務與備忘錄介面整理（build 15）

日期：2026-11-02。1.4.0（15）已封存並上傳內部測試；Apple 處理與可下載狀態請見 TESTFLIGHT.md。

## 調整

- 成績與排名：以 ScrollView／卡片取代 List；學期選擇、摘要數值、課程與成績分層呈現。學期依既有來源順序顯示，預設顯示最後一個來源區段，不自行推算平均或排名。
- 畢業門檻：總學分主卡、各門檻小卡、必修／選修等課程分類卡；課程明細與補充說明收合。採系統動態字體與適應寬度的欄數。
- 校方 `.main_credit` 與 `.total_credit` 分別存為 value／detail，不再合併為單一數值字串。舊畢業門檻快取保留於儲存層，顯示前要求重新抓取；離線時顯示需要更新，不把舊格式當成新結果。
- 備忘錄：將「這是哪一堂課的作業」改成「連結課程」；來源入口縮短為「Moodle 作業」。
- 作業設定：簡化為預設提醒與 Moodle 同步，保留提醒天數、停用、自訂優先及個人／團體作業同步行為。同步按鈕內顯示讀取狀態，移除重複說明。
- 課表：移除頂部大段刷新入口；只有編輯模式才在工具列顯示刷新圖示，保留無障礙名稱。
- 縮短校務登入、Moodle 課程與作業等頁面的重複提示；帳號／隱私資訊仍可展開查看。

## 驗證

- 同份 App 服務與模型的離線回歸通過：三位數／小數原值保留、兩個學分欄位分開、舊版畢業快取需更新、新格式 Codable 往返，以及既有同步／私人修改／提醒檢查。
- App Release 編譯及最終簽章封存成功；上傳結果請見 TESTFLIGHT.md。
- iPhone 16e 模擬器使用獨立預覽程式及合成資料，載入此次實際 SwiftUI 報表／作業設定 View，檢查淺色、深色與輔助使用放大字體。這不是正式 App 登入／校務端到端驗證。

## 尚待核對

使用者回報「畢業門檻有些數字呈三位數」。尚未確認根因；不可直接截短、除以十、推測小數點或把所有三位數視為錯誤。此次已分離原本合併呈現的欄位，但不宣稱這就修正了回報的數字問題。

本機校務探測 session 已過期。需要使用者重新執行 `python3 scripts/sis_probe.py login`，才能唯讀比對真實 HTML、校方格式轉換與 App 解析值。原始頁與憑證不落檔、不提交；數值格式仍須核對；build 15 供介面測試，不能視為數字問題已解決。

### 不經 Keychain 的單次診斷

若校務登入已成功但探測工具保存 session 時回傳 `keychain_operation_failed`，可在本機執行：

```sh
python3 scripts/graduation_diagnostic.py
```

此工具透過隱藏輸入登入，僅允許既有授權的 cof／ohs01 橋接與 `func=9_m` 畢業門檻頁；session、帳密與原始頁只在程序記憶體內，不寫入 Keychain 或檔案。它只輸出固定摘要及必修／選修等分類欄位的數字位數、是否有小數點、分隔符與單位等形狀，以及校方相關程式是否包含特定格式運算的布林值；不輸出實際學分、原始程式或身份資料。這項診斷不改變 App 的 Keychain 儲存方式，也不代表已修復其可能遇到的獨立問題。

使用者提供校方畫面顯示「已累計總學分」包含各類學分加總；先前將 `tag_total` 誤認為總學分，與校方的校訂必修分類不符。修正標籤並使舊解析版本快取需更新；真正累計總學分的 HTML 選擇器與數值讀取仍須核對，不能直接推測或寫死。
